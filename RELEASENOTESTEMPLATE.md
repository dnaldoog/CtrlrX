### This fork is reported as not working in MacOS M2.
If you would like to help debugging this problem or can confirm either way that it is *working/not working* on MacOS Silicon, please go to the [issues](https://github.com/dnaldoog/CtrlrX/issues) or [discussions](https://github.com/dnaldoog/CtrlrX/discussions) page.<br>
  Verify with `codesign -dv --verbose=4 <path>`.

#### Linux Installation instructions:

- **Debian/Ubuntu**: `sudo apt install ./ctrlrx-8.61-Linux.deb`
- - **Debian/Ubuntu**: `sudo apt remove ctrlrx`
- **Fedora**: `sudo dnf install ctrlrx-8.61-Linux.rpm`
- - **Fedora**: `sudo dnf remove ctrlrx`
